How are you running AI?

Vanilla works with local models and cloud providers.

Name your chats automatically?

Vanilla can read each conversation and pick a short title using a tiny local model. It downloads about 350 MB through Ollama and never sends your chats anywhere.

Local AI

Vanilla connects to Ollama at localhost:11434 by default. Only change this if you're running on a custom host or port.

Cloud provider

Pick a provider and paste your API key. You can change this any time in Settings.

Install a model

Search above to find GGUF models. Pick a repo, choose a quantization (Q4_K_M is a good default), and hit Install — it downloads and imports into your local Ollama.
