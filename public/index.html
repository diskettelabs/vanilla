To use LM Studio models:

  1. Open LM Studio.
  2. Go to the Developer tab in the left sidebar.
  3. In the Local Server section, click Start Server.

The local API server runs at http://localhost:1234/v1. Load a model in LM Studio, then check the connection below.

Web Search

DuckDuckGo works without a key. Brave can be more precise, but it needs a free API key from api.search.brave.com. When enabled, your latest question is searched before answering.

Workspace

When enabled, the assistant can create, read, and delete files in data/workspace/ only. File actions appear as chips above each reply. This works best with providers that support tool calling.

Your setup, your pace. Fast, private, and practical.

First things first: what should I call you?

We use your name in greetings and a few prompts. You can change it anytime.

Where should your model run?

You can run models locally for privacy, or connect a cloud provider for broader model options.

Want your chats named automatically?

Vanilla can auto-name chats using a small local model (about 350 MB via Ollama). You can skip this and rename chats manually at any time.

Import past chats from markdown?

If you've exported conversations as .md files from Vanilla (or another app), you can bring them right in.

Choose your dictation engine

Vanilla supports voice dictation for hands-free chatting. Pick the engine that fits your needs.

Almost there. Let's check your Ollama setup.

Vanilla connects to Ollama at localhost:11434 by default. Change this only if your Ollama server uses a custom host or port.

One more step: add your API key.

Choose a cloud provider and enter your API key. Keys are stored locally in your browser, and you can update them anytime in Settings.
