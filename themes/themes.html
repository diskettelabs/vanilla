Swap the logo, mascot, colors, accent, and more with a single JSON file.

JSON themes/ directory GET /api/themes

What is a theme?

A theme is a plain JSON file dropped into the themes/ folder next to the app. Each file becomes an entry in the Theme picker (Settings → UI → Theme). You can override colors, replace the brand logo and mascot, rename the app, customize the greeting and input placeholder, and inject your own CSS — all without touching the app code.

No restart needed for the UI: theme files are served from disk. The catalog endpoint (/api/themes) is read once on startup, so after adding or renaming a theme file, restart the app or refresh the page to see it appear.

Quick start

  1. Create a file like themes/my-theme.json.
  2. Give it a unique name and a displayName.
  3. Restart the app (or reload the page), open Settings → UI → Theme, and pick it.

Minimal valid theme:

// my-theme.json
{
  "name": "my-theme",
  "displayName": "My Theme",
  "description": "My first theme",
  "colors": {
    "background": "#ffffff",
    "text": "#1a1a1a"
  }
}

Schema reference

FieldTypeRequiredDescription
namestringyesUnique id used by the picker and as the file key. Should match the filename (e.g. my-theme.json → my-theme).
displayNamestringnoHuman name shown in the Theme picker. Defaults to the file name.
descriptionstringnoShort description of the theme.
versionstringnoTheme version, e.g. "1.0.0".
authorstringnoWho made the theme.
accentstringnoAny CSS color. Drives --accent (active toggles, links, the web-search pill).
colorsobjectnoPalette. Any keys you set are applied; omitted keys keep the defaults. See Colors below.
logostringnoAn inline SVG string that replaces the brand logo in the sidebar. The app injects class="brand-logo".
mascotstringnoAn inline SVG string that replaces the mascot everywhere: empty state, assistant message avatars, and the empty conversation list. The app injects the sizing classes.
appNamestringnoOverrides the document title (the browser tab text).
greetingstringnoFixed text shown in the empty chat state instead of the rotating greetings.
placeholderstringnoFixed text for the message input instead of the rotating placeholders.
faviconstringnoURL or data URI for the browser tab icon. Example: data:image/svg+xml,<svg…>.
stylesstringnoRaw CSS injected into the page (a <style> tag with id theme-styles). Great for fonts, glow effects, layout tweaks.

Colors

All keys are optional. Colors are applied as CSS custom properties on the root element.

KeyCSS variablePurpose
background--bgMain app background
text--textPrimary text color
userMessage--bubbleUser message bubble
assistantMessage--panel, --softAssistant message panel / soft surfaces
secondary--panel-strongStronger panels (dropdowns, headers)
surface--surfaceElevated surfaces: composer, modals, settings inputs & pickers
border--lineBorders and dividers
primary—Reserved / informational
statusBar—Reserved / informational

SVG guidelines

  • Provide the full <svg>…</svg> element, not a file path.
  • Do not include a class attribute on the root <svg> — the app injects the correct sizing class (brand-logo, empty-mascot mascot-svg, or assistant-mark mascot-svg).
  • Include a viewBox so the SVG scales (the logo is rendered ~117px wide; the message mascot ~28px).
  • Use fixed fills in your SVG when you want exact colors, or fill="currentColor" to inherit the surrounding text color.

API endpoints

GET/api/themes

Lists every *.json file in themes/ with its metadata, so custom themes appear automatically — no code changes required.

{
  "themes": [
    { "name": "aurora", "displayName": "Aurora",
      "description": "…", "version": "1.0.0",
      "accent": "#22d3ee", "hasLogo": true,
      "hasMascot": true }
  ]
}
GET/themes/<name>.json

Returns the full theme document for <name> (served statically from the themes/ folder). This is what the app loads to apply a theme.

Full example

A theme that changes everything at once:

{
  "name": "aurora",
  "displayName": "Aurora",
  "description": "Dark sky theme with a custom logo and mascot",
  "version": "1.0.0",
  "author": "You",
  "accent": "#22d3ee",
  "appName": "Aurora Chat",
  "greeting": "Ask the night sky anything.",
  "placeholder": "shoot for the stars…",
  "colors": {
    "background": "#0f1117",
    "text": "#e6edf3",
    "userMessage": "#1e293b",
    "assistantMessage": "#16181f",
    "secondary": "#20242e",
    "border": "#2a2f3a"
  },
  "logo": "<svg viewBox='0 0 120 26' xmlns='http://www.w3.org/2000/svg'>…</svg>",
  "mascot": "<svg viewBox='0 0 48 48' xmlns='http://www.w3.org/2000/svg'>…</svg>",
  "favicon": "data:image/svg+xml,<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 32 32'><circle cx='16' cy='16' r='14' fill='#22d3ee'/></svg>",
  "styles": ".top-bar { backdrop-filter: blur(8px); }"
}
Security note: logo, mascot, and styles are injected into the page as-is. Only install themes you trust, just like browser extensions.
Themes are plain JSON. Nothing to compile, nothing to install — just drop a file in themes/ and pick it from Settings.
